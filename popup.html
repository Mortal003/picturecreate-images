高级接口参数
高级配置填写指南（看不懂时可复制给 AI）

先判断是否真的需要高级配置：如果你的中转站兼容 Agnes、hfsyapi 或 OpenAI 图像接口，只需选择对应协议，填写 Base URL、API Key 和模型名称。只有接口文档明确不同，才选择“其他接口（高级）”。

  1. Base URL：填写接口根地址，例如 https://api.example.com 或 https://api.example.com/v1，不要填写完整的生成路径、任务 ID 或查询参数。
  2. 生成接口路径：填写“提交生图任务”的路径，例如 /v1/images/generations。通常是 POST。
  3. 查询接口路径：只有异步接口需要填写，例如 /v1/image/query/{task_id}。其中 {task_id} 必须保留，插件会替换成实际任务 ID。
  4. 请求模式：接口提交后直接返回图片，选“同步返回”；先返回任务 ID、再查询结果，选“异步任务”。选错会导致已扣费但找不到图片。
  5. 图片输入字段：按文档填写。OpenAI 兼容接口常用 extra_body.image；hfsy 类接口常用 reference_images；文档只写 image 时选 image。
  6. 任务 ID、状态、结果字段：填写 JSON 返回体中的路径，多个候选路径用英文逗号分隔。例如 data[0].url,result_url。路径从返回 JSON 顶层开始计算。
  7. 成功/失败状态：填写接口原样返回的状态值，大小写不敏感，多个值用英文逗号分隔。没有状态字段的同步接口不需要修改。
  8. 查询方法：自动模式会先用 GET，接口返回 405 或 501 时只回退一次 POST，不会重复提交生图任务。
  9. 认证方式：按接口文档选择 Bearer、x-api-key、api-key 或自定义 Header；Header 值始终来自上方 API Key 输入框。

不要把 API Key 写进截图、公开文档或发给 AI。发给 AI 时只提供脱敏后的请求示例和返回 JSON。
