自定义中转站配置
填写教程：以 Agnes Image 2.5 Flash 为例

Agnes 已在上方“中转站供应商”内置。此示例仅用于通过“自定义中转站”接入 Agnes 兼容接口时填写。

  1. API Key：填写 Agnes API Key，并点击“保存当前中转站配置”。
  2. Base URL：https://apihub.agnes-ai.com
  3. 生成接口路径：/v1/images/generations
  4. 模型名称：agnes-image-2.5-flash。也可填写 agnes-image-2.1-flash 或 agnes-image-2.0-flash。
  5. 请求模式：选择“同步返回”。Agnes 直接返回图片，不需要轮询任务。
  6. 图片输入字段：选择 extra_body.image（OpenAI / Agnes）。
  7. 图片结果字段：保留 data[0].url。若中转站只返回 Base64，则添加或保留 data[0].b64_json。

同步模式下，“查询接口路径”“任务 ID 字段”“任务状态字段”“成功状态”“失败状态”不会使用，可保留默认值。填写后点击“保存自定义配置”。
