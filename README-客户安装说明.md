# 商品生图助手 v0.1.0

## 安装

1. 解压客户 ZIP。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 点击“加载解压缩的扩展”并选择解压后的插件文件夹。
5. 固定“商品生图助手”，在商品页面打开侧边栏。

## 激活

首次打开会显示机器码。点击“复制”，把机器码发给授权人员，收到激活码后粘贴并点击“激活插件”。

激活码绑定当前浏览器安装并有有效期。清除扩展数据、换浏览器或换电脑后需要重新授权。

## 使用

激活后按原流程选择参考图、填写提示词、生成图片、保存到本地文件夹或自动上传到店小秘。首次保存时请允许文件夹访问权限。

## 升级

收到新版 ZIP 后，关闭侧边栏，解压新版文件，将文件覆盖到原来的扩展目录，然后在扩展管理页点击“重新加载”。不要移除扩展、不要点击“清除扩展数据”，这样 API 配置、历史记录、激活状态和保存目录授权会保留。

图片和 JSON 保存在你选择的本地文件夹，不会随插件升级删除。

## 注意

API Key 由客户自行填写并保存在浏览器本地。请勿把 API Key 或激活码公开给其他人。
