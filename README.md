# 商品生图助手（MVP）

这是一个无需构建工具的 Chrome/Edge Manifest V3 插件：扫描当前页面图片，选择参考图，输入提示词后调用 GPT-image-2，并展示/下载生成结果。

## 今天运行

1. 打开 chrome://extensions（Edge 使用 edge://extensions）。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件夹 D:\生图插件。
4. 打开商品图片页面并刷新页面。
5. 点击工具栏中的“商品生图助手”，侧边栏会直接打开工作台；填入中转站 API Key，选择图片，输入提示词，点击“生成图片”。也可以在页面右下角点击绿色浮动入口打开侧边栏。

## 重要限制

- 当前版本直接在浏览器中使用 API Key，仅适合个人测试。正式交付客户时，应改为你的后端代理并加入激活码校验。
- 支持 Agnes Image 2.5 Flash 同步 URL/Base64 返回，以及 hfsyapi GPT-image-2 异步 task_id 轮询；批量选择几张参考图就提交几张任务，全部任务返回后才结束进度条。
- “选择参考图”支持网页扫描和本地多选上传，单次最多 6 张；本地图片会以 Data URI 方式发送给中转站。
- 只有 http(s) 图片 URL 或 Base64 图片能直接被中转站读取；blob:、登录保护图片需要先经后端上传转换。
